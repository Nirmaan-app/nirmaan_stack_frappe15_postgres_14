Create BOQ from Template

18 decisions resolved via /grill-with-docs. This is the design of record — the input to the implementation plan + ADR-0013. Nothing built yet.

The feature in one paragraph

A second entry point beside Upload BOQ — Create from Template — lets a user compose a brand-new BOQ from a curated skeleton (MEP BOQ..xlsx). A template is a project-less BOQs doc (is_template=1) authored through the existing wizard. On create, the chosen template sheets are deep-cloned into a fresh, project-bound BOQ — already classified & parented, landing at Parsed. The user opens each sheet in an enhanced Review screen: he selects the rows he needs (deselecting a preamble cascades to its subtree), optionally creates rows, and fills a quantity on each selected line item. He finalizes — and from there commit → tender → pricing run exactly as today.

Proposed build slices (for the plan)

1
Schema + clone worker (backend). Additive fields (is_template, status, origin, source_template, is_excluded); enqueued clone_template worker (flatten→strip→bulk-insert) + socket; templates filtered from BOQ lists.
2
Entry + Templates management (frontend). 2nd picker option, sheet picker, create flow with clone-progress; Admin+Estimates Templates page (new/edit/publish/deprecate/duplicate).
3
Hub template-origin behavior. Suppress Configure/Parse; SheetCard stepper from ②Review.
4
Selection + cascade. templateSelection.ts pure helpers; set_row_excluded endpoint (subtree cascade, both directions); checkbox column in ReviewTree (memo-safe).
5
Row create/delete. create_review_row (renumber-on-insert + remap) / delete_review_row; create form (class+parent+desc+unit); auto-select.
6
Qty on selected line items. Gate the existing editable qty descriptor to selected line_item rows (single-area); soft qty advisory.
7
Finalize + commit on included subset. Filter gate + commit pipeline to is_excluded=0; verify tender/pricing end-to-end.

  • Mixing template + uploaded sheets in one BOQ (Q10).
  • Formal template versioning / supersede chains (Q12).
  • Template-level amount-formula pre-seed for pricing (Q8).
